# Module 4

## Version Control with Git and Github

### What I learned

In this module, I learned the basics of version control with Git and GitHub. We went through installing Git locally, creating a GitHub account, and setting up our first repository. Then I worked through the basic workflow of adding changes, committing, and pushing. I also learned how to structure my commit messages better. After that, I worked with branches and pull requests, and finished the module with our weekly activity.
